# Бетта Клиника — сайт

Статический сайт (HTML + CSS + JS), сборка не нужна. Открыть локально: `python3 -m http.server 8420` в этой папке, затем http://localhost:8420

- `index.html`, `about.html`, `help.html`, `devices.html`, `blog.html`, `promo.html`, `contacts.html`, `privacy.html` — основные страницы
- `uslugi/` — страницы услуг, `articles/` — статьи блога
- `assets/` — картинки, видео, иконки
- `sitemap.xml`, `robots.txt` — для поисковиков; `.htaccess`, `redirects.csv` — 301-редиректы со старых адресов (Apache)
